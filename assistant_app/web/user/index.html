正在检查真实生成条件

确认是否已经同时启用视频和语音渠道。

  1. 01
    选择“开始制作”或“一键成片”

    常规制作生成一个带语音和字幕的预览镜头；一键成片会逐镜生成、配音、烧录字幕并合片。

  2. 02
    故事与视觉结构化规划

    模型输出必须通过 JSON 校验；失败会自动重试，而不是把空文本流入下游。

  3. 03
    原生声画优先、外部语音兜底

    MiniMax H3 镜头优先保留同步对白、情绪、音效与配乐；没有原生音轨时才调用语音渠道，并按对白时间窗烧录中文字幕。

  4. 04
    技术质检拥有否决权

    系统检查每镜和最终合片的视频轨、音轨、字幕标记和时长；未通过时项目标记失败。
