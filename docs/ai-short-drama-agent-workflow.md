# AI 短剧多 Agent 制作流程

## 设计结论

AI 短剧不应被建模为一次“文本生成视频”调用，而应被建模为由 1 个总导演 Agent 编排、8 个专业 Agent 分别验收的门禁式生产流水线，共 9 个 Agent。每个阶段都需要明确的输入、交付物、验收标准、失败回退目标和人工确认点。

## 总导演 Agent

总导演 Agent 不直接替代所有专业工作，而是维护全局目标和跨环节约束：

- 维护项目圣经：受众、题材、核心命题、人物弧光、画幅、时长、视觉和声音风格。
- 编排任务依赖，允许无冲突任务并行，阻止未通过的交付物流入下游。
- 汇总专业 Agent 的判断摘要、风险和建议，向用户提出最少但关键的决策。
- 维护连续性记忆：人物身份、服装、道具、场景、时间、光线、视线、情节事实和声音身份。
- 当质检失败时，将问题准确退回责任环节，并保留版本和生成参数。

## Agent 动态模型路由

Agent 与模型解耦，不把某个角色永久绑定到固定模型。每次启动或可用模型目录变化时，路由器根据任务能力重新匹配；首选 GLM、DeepSeek、Qwen 三个模型家族，全部不可用时才降级到其他兼容模型。

- 总导演、策划、编剧和终审优先匹配推理与长上下文能力，通常优先 DeepSeek 推理型号，再考虑 Qwen、GLM。
- 美术、分镜、摄影和剪辑优先匹配视觉理解能力，通常优先 Qwen-VL、GLM-4V 等多模态型号。
- 声音 Agent 优先匹配 Audio/Omni 能力；没有音频模型时，使用文本模型完成台词、情绪与声音设计，把声学质检交给专用工具。
- 每次匹配都记录可用模型列表、选中模型、能力命中、降级状态和匹配理由，页面向用户展示当前实际使用的模型。

## 八个生产关卡

| 关卡 | 负责 Agent | 核心交付物 | 必须把关的关键点 | 不通过时回退 |
| --- | --- | --- | --- | --- |
| 1. 创意立项 | 策划 Agent | 一句话故事、受众假设、核心钩子、单集目标 | 前几秒能否建立人物/关系/冲突；题材是否适配短剧；是否具备追看问题 | 重新定义选题或钩子 |
| 2. 剧本节拍 | 编剧 Agent | 分场剧本、节拍表、对白、情绪曲线 | 信息密度、人物动机、台词可演性、单集闭环、结尾悬念 | 回到具体场次或立项 |
| 3. 资产定妆 | 美术 Agent | 角色表、表情/角度参考、场景表、道具表、视觉圣经 | 角色可识别性、跨镜一致性、版权与肖像、风格和色彩规则 | 重新定妆或更换资产 |
| 4. 分镜设计 | 分镜 Agent | 镜头表、构图、景别、焦段、运镜、时长、起止关键帧 | 叙事可读性、轴线与视线、节奏、镜头可生成性、资产连续性 | 回到镜头或剧本节拍 |
| 5. 镜头生成 | 摄影 Agent | 每镜候选视频、模型和提示词记录、种子/参考图 | 人脸与服装漂移、动作物理、闪烁、镜头意图、首尾帧衔接 | 重生成、换模型或拆镜 |
| 6. 声音表演 | 声音 Agent | 对白、声纹、口型、环境声、拟音、音乐 | 声音身份、情绪表演、口型同步、响度、音乐版权 | 重配音或调整时长 |
| 7. 剪辑合成 | 剪辑 Agent | 粗剪、精剪、字幕、调色、混音、特效 | 先验证叙事再精修；节奏、声画同步、字幕安全区和竖屏适配 | 退回镜头、声音或剧本 |
| 8. 终审发布 | 监制 Agent | 终审报告、母版、封面、标题和平台版本 | 叙事、连续性、技术质量、版权/肖像/内容合规、平台规范 | 精确退回责任 Agent |

## 页面应该展示什么

1. 工作区一级分流：知识对话负责问答和个人数据积累；导演工作室负责结构化创作项目。
2. 总导演状态：当前目标、整体进度、阻塞点、下一步动作和跨环节风险。
3. 流水线：所有关卡同时可见，清楚区分已通过、进行中、被阻塞、待开始和需人工确认。
4. Agent 工作台：当前 Agent 的职责、交付物、验收项、判断摘要、证据和建议动作。
5. 连续性记忆：锁定的角色、场景、道具、剧情事实和不可违背的创作规则。
6. 分镜/时间线：把抽象任务落到可视镜头，支持查看候选、版本和问题回退。
7. 模型路由：每位 Agent 显示当前动态匹配的模型和原因，而不是展示固定、可能过期的模型名称。

“展现 Agent 思考”应实现为可审计的判断摘要，而不是模型隐藏推理原文。建议记录：使用了哪些输入、检查了哪些规则、发现了什么风险、为什么给出当前建议、置信度、交付物版本，以及需要谁来决定。

## 数据模型建议

- `ProductionProject`：项目圣经、总体状态、当前版本。
- `Episode`：单集目标、剧本、时长、状态。
- `ProductionStage`：负责人、依赖、状态、门禁结果、回退目标。
- `AgentRun`：输入引用、模型、开始/结束时间、结果、成本和错误。
- `DecisionLog`：判断摘要、证据引用、风险、建议、人工决定。
- `Asset`：角色/场景/道具/声音参考、锁定状态、版本和版权信息。
- `Shot`：镜号、场次、构图、动作、对白、时长、提示词、参考资产和候选素材。
- `QualityIssue`：问题类型、严重级别、责任阶段、定位和修复状态。

## 调研依据

- Runway 的长视频制作指南强调先建立叙事基础和分镜，再把每个分镜作为短片段生成，使用角色参考维持一致性，最后先做粗剪。
- Runway 的分镜指南强调逐镜标注机位、时长和动作，并在生产前检查人物、服装、光线、地点、节奏和连续性。
- Runway Workflows 将生成流程表达为可连接的输入、LLM、图像、视频和音频节点，适合做可重复的生产管线。
- 国内短剧工具的公开流程普遍覆盖剧本解析、主体资产、分镜、画面/视频、配音和非线性剪辑；其中“主体资产”被作为跨镜头一致性的核心锚点。
