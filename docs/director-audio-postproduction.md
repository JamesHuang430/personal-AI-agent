# 导演工作室：配音、字幕与独立配乐

## 当前实现

在项目页点击“配音、字幕与配乐”。草案/分镜待确认阶段允许修改；配音投入制作后锁定。
新建一版会复制公开设置，但不复制旧试听任务或供应商提交状态。

- 自动模式保留既有行为：动态视频优先原声，白板用默认配音渠道。
- 明确选择 Edge 或 MiniMax 音色后统一使用所选音色与语速。当前音色列表包含四个 Edge
  音色与后台当前渠道的默认 MiniMax 音色，不自动联网枚举供应商目录。
- 选定外部配音会替换动态视频的整个原音轨（包括原配乐/音效），不保证口型同步。
- 逐镜试听使用最终分镜的真实台词；只有用户点击才入队。MiniMax 试听可能收费。
  Edge 不需要配置 API Key，但依赖网络服务，没有可用性保证。
- 试听身份包括台词、声音参数、渠道 ID、模型、地址和音频格式。同参数重复点击复用同一
  SpeechJob；正式制作复用当前匹配的试听。失败或结果不明的任务不自动再次扣费。
  试听仍在生成时禁止确认，避免试听 worker 与导演任务同时提交同一配音。
- 明确音色的动态视频配音超过镜头时长时停止，避免截断台词；白板仍按实际音频延长镜头。

## 字幕

Edge 流式返回的单词边界随音频一并保存；已知支持的 MiniMax speech 模型开启字幕选项，
读取其官方域名 HTTPS 字幕文件。下载不带 Authorization、不跟随重定向，限制大小和时间。
不支持的返回地址或无效字幕不会触发再次合成音频。

仅在返回文本与原台词匹配、时序单调且不越界时采用渠道时间戳，保留原台词标点并合并短词。
否则明确退回估算。没有安装 Whisper、下载转写模型或宣称强制对齐。
视频原声仍使用原时间窗；渠道时间戳也需要观看复核。

字幕提供简洁白字、大字、深色底板三种预设；白板继续支持同台词 SRT 导入和手动校时。
人工改动时间后不再标记为原始渠道时间戳。

## 背景音乐

首版从用户自己的已完成音乐任务中选择，不额外生成音乐、不读取用户提交的服务器路径。
暂未提供上传背景音乐/录音或第三方音乐库。音乐原文件可以在面板试听。

音乐在最终合片（或首镜交付片）统一混合：独立音量、循环、淡入淡出、可选侧链压低及峰值限制。
中间镜头与原文件不覆盖，失败恢复不会在已经混音的文件上重复叠加。
压低以原音轨响度为信号，尤其原声视频不是人声分离；已有原配乐会保留并与新音乐叠加。
选择了音乐但文件失效或混音失败时明确失败，不静默交付缺少音乐的成片。

## 验证

`tests/test_director_audio.py`：字幕文本和时序校验、异常降级、Edge 边界保存、
MiniMax 下载来源/无凭证转发、设置约束与关闭配乐短路。
`tests/test_postgres_execution.py`：试听所有权、重复点击、确认门禁、正式制作复用、
迁移保护及真实 FFmpeg 混音，通过合成音频频谱检查侧链压低效果。
`tests/web/creative.test.mjs`：显式点击才试听、参数保存、确认摘要更新、只读锁定。
供应商返回使用测试数据；没有做真实付费配音验收。
