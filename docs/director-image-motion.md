# 图文动效产线

制作方式新增 `image_motion`；新项目默认仍是 `whiteboard`，旧项目保持原模式。
可从导演工作室或聊天中的导演工具选择。此模式不提交视频模型任务，也不在失败后切换渠道。

## 制作步骤与费用

1. 文本规划、总导演预演、用户确认分镜。可先逐镜上传自有图片，并设置/试听配音。
2. 缺图时调用已配置图片渠道，旁白使用共享语音设置和试听缓存。
3. 本地 FFmpeg 合成完整图片的轻微推拉平移、字幕、旁白与淡入淡出。
4. 合片后复用独立背景音乐混音与技术检查，交付 MP4。

不执行白板分区标注，不要求再次确认描线区域。生成图片后自动合成，建议先使用首镜预览。
本地合成不产生视频模型费用，但文本规划、生图、MiniMax 配音可能收费。Edge 无需渠道密钥，
仍依赖外部网络服务；上传图片不消除文本或配音费用。

## 当前效果与边界

- 24 fps；按镜头序号循环使用推近、拉远、向右/向左平移。放大幅度最多 8%，并非真实物体运动。
- 图片按原比例缩放，画幅不匹配时留底色，不强行拉伸。轻微动效可能裁切边缘，主体请留安全区。
- 每镜约 0.25 秒画面淡入/淡出；这是独立淡入淡出，不是镜头交叉溶解。
- 与白板一致，按最多约 35 秒拆分规划镜头；实际配音较长时延长片段，合片不裁掉旁白。
- 字幕优先采用校验通过的配音时间戳，否则标记为估算；复用三种字幕样式。
- 同模式失败恢复复用已完成图片、配音和镜头；输出先写临时文件，成功后替换，失败不覆盖旧成品。
- 暂不支持逐镜选择动效、上传录音/背景音乐、素材库搜索、Whisper 强制对齐或图文字幕手工编辑台。
- 没有新增数据库列或复制 MoneyPrinterTurbo 源码。

验证包括模型调用边界、模式选择/新建一版、横竖屏真实 FFmpeg 动效、长旁白不裁切、
上传权限、成片技术检查、恢复复用和失败临时文件清理。测试不调用真实生图、配音或视频模型。
