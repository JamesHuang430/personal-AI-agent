# 白板产线（字幕分区 + 上游连续笔迹）

新建导演项目默认 `production_mode=whiteboard`；`video` 保留既有动态视频逻辑。
数据库迁移将已有项目标记为 `video`，不会改变正在执行的老任务。

## 流程和费用

故事草案 → 文本规划与预演 → 用户确认分镜 → 每镜一幅图片与旁白 → 视觉模型看图标注 → 用户确认分区与时间 → 上游连续笔迹渲染 → 本地配音、字幕、合片 → MP4。
完整成片按约 25–35 秒一镜分段（短片可不足 25 秒）；常规试片仍是 4 秒。

- 默认从运营后台独立配置的 MiniMax 图片渠道生成图片，支持 `image-01` / `image-01-live`。
- 语音复用已有语音渠道，不自动复用其他渠道的密钥。
- 分镜待确认时可为每镜上传 PNG/JPEG/WebP（最大 12 MB、1600 万像素），该镜不再提交生图。
- 文本、生图、配音可能收费；仅本地渲染没有视频模型调用费，仍消耗服务器资源。
- 白板失败不会升级为动态视频；图片请求一旦提交但结果不明，不自动重发，以免重复扣费。
- 失败后的替代图片可重新上传并再次确认分镜；成功落盘的图片、配音和镜头在恢复时复用。

## 配置与部署

运营后台 → 图片渠道 → 新增 HTTPS 地址（默认 `https://api.minimaxi.com`）、模型与 API Key，启用。
密钥加密入库且不回显；配置保存不做付费试调用。独立检查生图权限与余额。
默认配音需启用语音渠道；在声音面板选择 Edge 时无需渠道密钥。全部上传自有图片时不要求图片渠道存在。

依赖：FFmpeg/ffprobe、Noto Sans CJK、NumPy、OpenCV headless、Pillow。
运行 `alembic upgrade head`；重新构建并部署 API、运营后台与 worker。
白板输出标准尺寸为 720×1280 / 1280×720，高清沿用项目的 1024×1792 / 1792×1024。
项目字段 `768P` / `2K` 为兼容现有渠道的档位名，界面显示白板实际像素尺寸。

## 明确限制

已直接集成 `geeklee/srt-whiteboard-animation` 固定版本
`696a7243c0e6ffb6827676e539c2ca5ebae2bf6b` 的区域渲染器与连续笔迹构件，
位于 `assistant_app/vendor/srt_whiteboard`，保留 MIT 许可证与修改说明。
不是安装全局 Skill，也不是照搬其桌面文件夹工作流。原基础渲染器保留供历史测试使用，
生产白板路径改为 `whiteboard_stream`，不会静默降级为整图描线或动态视频。

图片、配音先落盘；原图和字幕交给项目已分配的视觉模型，返回按字幕事件排序的区域建议。
模型不支持图片或标注无效时，不编造坐标、不重复生图，进入同一编辑台手工框选。
自动坐标不保证精确，必须对照原图复核。分区保存后仍需确认全部分区才正式渲染。

编辑台支持框选/重画区域、像素坐标尺寸、上/下移顺序、开始与持续毫秒、
字幕关联、保护区、grid/skeleton、同旁白 SRT 导入，以及低清无声真实笔迹预览。
SRT 导入用于修正当前镜头字幕时间，不是整片 SRT 自动拆场景入口。
字幕优先使用匹配有效的渠道时间戳，否则按音频时长与文字长度估算，不是逐字强制对齐。
配音较长时延长镜头。声音与配乐设置见 [声音后期](director-audio-postproduction.md)。
字幕文字必须与既有旁白一致；改写旁白应新建一版，避免错误复用配音。

标注 v2 绑定原图 SHA256 和像素尺寸；修改图片作废标注，修改标注改变确认摘要。
保存时检查编号、边界、串行时序、关联字幕和至少 0.5 秒尾帧。
允许掩码扣除后续区域及保护区；每个区域独立 ink→color，不在结尾强制显示未标注像素。
未覆盖对象会保持隐藏，需通过预览检查覆盖完整性。区域以矩形表示，不等于实例分割。

适配层采用固定 24fps、精确帧调度和现有偶数输出尺寸；修复上游空白区域异常，
绕开其时长累积、最终整图突然揭示和 PyAV 合片分支。不包含带作者标识的手图，使用程序笔尖。
低清预览按已保存标注摘要缓存，每用户串行生成；仅本地计算，预览不包含声音和烧录字幕。
正式渲染继续在独立子进程中执行，保留现有 600 秒超时/取消和工作租约机制。
技术质检检查轨道和时长；图片一致性、讲解准确性和绘制顺序仍需人工验收。
现有动态视频的重新配音入口不支持白板项目，需新建一版。

## 验证

`tests/test_whiteboard.py` 覆盖默认值、旧项目兼容、确认门禁、成本隔离、图片校验、
不明提交防重发、字幕分段以及真实 OpenCV 编码（空白和稀疏图片）。
`tests/web/creative.test.mjs` 覆盖制作方式选择和上传入口。
`tests/test_postgres_execution.py` 的白板集成测试使用隔离 schema、测试图和合成音频，
不调用付费服务，验证上传权限、迁移兼容和真实 FFmpeg 音视频成片。

`tests/test_whiteboard_annotations.py` 覆盖原图绑定、非法区域/字幕/时序、grid/skeleton
真实编码、先右后左的叙事顺序、保护区、未标注对象不泄露、全空白/完全遮挡场景及帧数。
前端测试覆盖分区编辑保存、XSS 转义、轮询不覆盖编辑；数据库测试覆盖两阶段门禁、
所有权、过期摘要拒绝、标注确认后实际音视频合成。分区接入本身没有增加数据库列；
随后新增的声音后期需要 `20260915_0021` 迁移。
